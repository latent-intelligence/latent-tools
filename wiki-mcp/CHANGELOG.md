# latent-wiki-mcp

One line per release; the annotated tag `wiki-mcp-v<version>` carries the same line.

- 0.1.2 (2026-10-25) — the reader resynced from latent-wiki 45b3974: a refusal is one line with `isError` set, no footer and no path, and a missing page is refused alike by every tool; `wiki_neighbors` takes `offset`; a `type`, `tag`, `status`, `part_of`, `where` key or `wiki_view` name nothing can match is refused with the values that can; a missing or wrongly typed argument and a number below its floor are refused, not clamped; `wiki_evidence` puts its `Next:` line before the footer; `cut:` names what an offset, a section, a depth or `wiki_raw`'s other cited entries left out. Also `--print-config` warns when run from uv's cache (`uvx`), whose path a pasted config would lose; `--insecure-local` on a host outside its exact loopback list names the host; a store's own `wiki/` folder is refused as not a deployment folder; the docs say what the declaration check reads and refuses.
- 0.1.1 (2026-10-25) — the reader resynced from latent-wiki 28db78d: concurrent searches of one store no longer share a connection unguarded, a `links` value that is not a list is ignored, raw text in the context store is read only once its stamp is checked, a `name:` that differs from the deployment's folder is refused, and the copied files' spec paths now read `docs/contracts/`.
- 0.1.0 (2026-10-21) — a standalone, read-only MCP server over a published latent-wiki store, local or `s3://`; the reader copied from latent-wiki 991549f.
