# latent-records-mcp

One line per release; the annotated tag `records-mcp-v<version>` carries the same line.

- 0.2.0 (2026-11-06) — the read path resynced from kb-store fe6e28c, the store package formerly latent-records: it reads stores stamped `records.store`, the name kb-store writes, and no longer the old one; `locations.py` is copied too, so a location is made as kb-store makes it, and a Windows `file://` store keeps its drive. `--store <folder>` serves a store by its own folder, local or any URI, with no deployment; a deployment's declaration is read for `output:`, and `root:`, its older name, still serves; hits carry a `citation` when the store's input was a core store; the `equations` target is searched and described; `contains` also looks in equations; `get` takes an equation's id, and its refusal names every part kind; a search of `equations` in a store built before them finds nothing, as `contains` does, rather than failing; `recommended` prefers a model made for the target's modality, a text model before CLIP for text; `--print-config` names `HF_HUB_CACHE` and `HF_HUB_OFFLINE` in `env` when set, for a machine with no internet access. The fixture store is rebuilt by kb-store 34d6db4.
- 0.1.2 (2026-10-25) — the read path resynced from latent-records e9eb62a: `serverInfo.version` reports this package's version (it was empty); a `record_id` not in the store and an empty `query` are refused, as is an argument of the wrong type, in one line; `describe` adds the `recommended` space per target, and `queryable` and `install` per space, naming `latent-records-mcp[clip]`; a model's first download is logged. `--print-config` lists the variables `root:` names in a stdio block's `env`, and `[::1]` is a loopback host. Also `--print-config` warns when run from uv's cache (`uvx`), whose path a pasted config would lose; `--insecure-local` on a host outside its exact loopback list names the host; the docs say what the declaration check reads and refuses.
- 0.1.1 (2026-10-25) — the read path resynced from latent-records 5a75235: a local root expands `$VAR` before `~`, so a variable holding `~` resolves under home; the copied files' spec paths now read `docs/contracts/`.
- 0.1.0 (2026-10-21) — a standalone, read-only MCP server over a published latent-records store, local or in object storage; the read path copied from latent-records b7ca93c.
